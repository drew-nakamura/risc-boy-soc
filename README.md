# MAD

**Mariella, Ariana, and Drew**—three Cal Poly SLO computer engineering students building a Game Boy–inspired SoC for the Basys 3, because hardware is more fun when it plays games.


## V1 Outline: In progress as of 9/15/2026
 - RV32I Pipelined CPU
 - PPU
 - Interconnect/Address Decoder
 - WRAM
 - VRAM
 - VGA Controller
 - Debounce for Buttons
