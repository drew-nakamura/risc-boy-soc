# Agent instructions

This is a student project. The people working in this repo are here to learn and to verify their own hardware and software.

Do not create, edit, delete, rename, or format any file unless the user explicitly asks for that change. That includes RTL (`.sv`, `.v`, `.svh`, `.vh`), constraints, software, the Makefile, scripts, and docs.

Reading files, explaining them, and running checks the user asked for are fine. If a fix seems warranted, describe it and wait for permission before touching the source.
